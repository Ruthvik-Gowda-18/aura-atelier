# Aura Atelier — Frontend Client

The luxury React 19 single-page application for Aura Atelier. Built with modern styling, reactive Context API state management, and real-time inventory synchronization.

## 🛠️ Tech Stack
- **Framework**: React 19
- **Build Tool**: Vite 8
- **Routing**: React Router v7
- **HTTP Client**: Axios with credentials / HttpOnly cookie support
- **Icons**: Lucide React
- **Typography & Styling**: Custom Luxury Theme & CSS Variables

## 🏃 Local Development
```bash
npm install
npm run dev
```

Build for production:
```bash
npm run build
```
